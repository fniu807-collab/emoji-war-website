# 安装说明

## 覆盖方式

1. 解压 `emoji-war-v7-launch-optimized.zip`
2. 进入解压后的文件夹
3. Ctrl + A 全选里面的所有内容
4. Ctrl + C 复制
5. 打开：

```text
C:\Users\Administrator\Desktop\emoji-war-website
```

6. Ctrl + V 粘贴
7. 选择“替换目标中的文件”

## 运行

```bash
cd C:\Users\Administrator\Desktop\emoji-war-website
npm install
npm run dev
```

打开：

```text
http://localhost:5173/
```

## 测试顺序

1. Connect Wallet
2. Switch to BNB Mainnet
3. 刷新 V7 数据
4. Select Army
5. Approve
6. Burn
7. Claim Realtime
8. Claim Season Bonus
9. Claim All

确认本地正常后再 Push 到 GitHub。
