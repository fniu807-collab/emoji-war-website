## 更新你当前网站的方法

1. 下载并解压这个压缩包
2. 打开解压后的 `emoji-war-war-panel-v2`
3. 复制里面所有文件
4. 粘贴覆盖你电脑里原来的 `emoji-war-website` 文件夹
5. 打开 GitHub Desktop
6. Summary 写：upgrade war panel
7. 点击 Commit to main
8. 点击 Push origin
9. 等 Vercel 自动更新网站
