## 用户流程

买入 → 选择军团 → 授权 → 燃烧 → 领取 BNB

## 使用方法

1. 解压本包
2. 把里面所有文件复制到：

```text
C:\Users\Administrator\Desktop\emoji-war-website
```

3. 选择覆盖同名文件
4. 运行：

```bash
npm install
npm run dev
```

5. 打开：

```text
http://localhost:5173/
```
